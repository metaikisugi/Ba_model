# BA モデル シミュレーター

Barabási-Albert (BA) モデルのシミュレーションと可視化を行うPythonプログラムです。
スケールフリー・ネットワーク（少数のハブに接続が集中する性質を持つグラフ）の生成過程を、3つの異なる手法でアニメーション表示します。

## 概要

このプログラムは、優先的選択（度数が高い頂点ほど新しいエッジが繋がりやすい性質）を持つグラフ生成モデルを実装しています。

### 実装されている3つのモデル

#### 1. HALF モデル
- **特徴**: 端点のプール管理による実装
- **仕組み**: 
  - 各ステップで「受け皿（L）」と「矢（R）」のペアを生成
  - Rがランダムに既存の端点を選択
  - Lを選んだ場合はそこに接続、Rを選んだ場合はそのRが指しているLへ「ジャンプ」
  - このジャンプ機構により、度数に比例した選択を自動的に実現

#### 2. LCD モデル (Linearized Chord Diagram)
- **特徴**: 幾何的な配置による実装
- **仕組み**:
  - [0,1] の区間上に弦（Chord）の端点をランダムに配置
  - 右端点をソートし、左端点がどの範囲に含まれるかで接続先を決定
  - 数学的に厳密な解析が可能な手法

#### 3. Standard BA モデル
- **特徴**: 教科書的な標準実装
- **仕組み**:
  - 新しい頂点が追加されるごとに、既存の全頂点の度数を確認
  - 「度数 ÷ 全体の度数の合計」の確率で接続先を選択
  - 最も直感的でわかりやすい実装

## 必要なパッケージ

```bash
pip install numpy matplotlib
```

## 実行方法

```bash
python Ba.py --mode [half|lcd|standard] --n [頂点数] --m [エッジ数] [オプション]
```

### 主要な引数

- `--mode`: モデルの選択（`half`, `lcd`, `standard`）
- `--n`: 縮約後の真の頂点数（デフォルト: 30）
- `--m`: 縮約サイズ（1ステップで追加するエッジ数、デフォルト: 3）
- `--fps`: アニメーションのフレームレート（デフォルト: 30）
- `--seed`: 乱数シード（デフォルト: 0）
- `--print_all`: 全履歴を一度に表示（デフォルトは増分表示）

### HALF モデル専用オプション

- `--pool_show`: プール表示で表示する端点数（デフォルト: 260）

## 実行例

```bash
# HALFモデルの実行
python Ba.py --mode half --n 40 --m 3 --fps 30 --seed 0 --pool_show 300

# LCDモデルの実行
python Ba.py --mode lcd --n 40 --m 3 --fps 30 --seed 0

# 標準BAモデルの実行
python Ba.py --mode standard --n 40 --m 3 --fps 30 --seed 0
```

## 可視化の内容

実行すると、以下のパネルが表示されます：

### HALF モデル
- **左上**: 端点プールの表示（円=L、四角=R）
- **左下**: 真の頂点の度数分布
- **右側**: グラフの物理レイアウト表示

### LCD モデル
- **左上**: [0,1] 区間上の弦の端点（丸=左端L_t、四角=右端R_t）
  - 丸の色：接続先ノード v(k) の色
  - 四角の色：現在のノード v(t) の色
- **左下**: ソートされた右端点とW境界
- **右上**: 度数分布
- **右下**: グラフの物理レイアウト表示

### Standard BA モデル
- **左上**: 現在のステップ情報（新しい頂点と接続先）
- **左下**: 度数分布（選択された頂点を強調表示）
- **右側**: グラフの物理レイアウト表示

## ターミナル出力

アニメーション実行中、ターミナルに各ステップの接続情報が表示されます：

- **HALF**: `R_t -> L_receiver` の形式
- **LCD**: `R_rank -> receiver rank` の形式
- **Standard**: `new node -> [接続先リスト]` の形式

## 技術的な詳細

- **頂点の縮約**: `m` 個のステップを1つの「真の頂点」としてまとめる手法を使用
- **物理レイアウト**: バネモデル（Spring Layout）による力学的配置
- **安定した色**: ハッシュ関数により各頂点に一貫した色を割り当て
